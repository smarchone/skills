# taste

Skills that encode design taste learned by iterating with an agent, so the next project starts from what already worked.

## Skills

| Skill | Use when | What it does |
|---|---|---|
| [`/github-page`](github-page/SKILL.md) | You want a GitHub Pages landing page for a project | Builds a one-screen `docs/index.html` that sells the idea without demanding attention: narrow column, one box, footer above the fold, verified at laptop and phone sizes |
| [`/visual-blog`](visual-blog/SKILL.md) | You have rough notes for a blog post and an illustration in your head | Writes a short, punchy post as one HTML page built around a side-by-side animated GIF of the idea, plus one small inline diagram |

## Install

```sh
npx skills add smarchone/skills/taste/github-page
npx skills add smarchone/skills/taste/visual-blog
```
