# Skills

A catalog of my Claude skills. See them run: **https://smarchone.github.io/skills/**

## Install

As Claude Code slash commands (`/productivity:intuition`, `/systems:rebuild`, ...). Rerun to update:

```sh
npx degit smarchone/skills/commands ~/.claude/commands --force
```

As skills, one at a time:

```sh
npx skills add smarchone/skills/<group>/<skill>
```

## Conversations worth keeping

Reports and panels turn a session into something worth reading. [`/golden`](productivity/golden/SKILL.md)
saves it, and the saved sessions become a blog.

**report · panel → `/golden` → blog**
