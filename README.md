# skills

My agentic skill systems for Claude Code.

## Groups

| Group | Skills | For |
|---|---|---|
| [ideas](ideas/README.md) | `/idea-establish`, `/idea-attack`, `/opine` | Shaping and stress-testing an idea |
| [productivity](productivity/README.md) | `/intuition`, `/nail-on-the-head`, `/feel`, `/intuition-panel`, `/product-panel` | Understanding things faster |
| [systems](systems/README.md) | `/origin-story`, `/evolve`, `/adoption`, `/build-vs-buy` | Studying a technology, company, or system |
| [exp](exp/README.md) | `/explain-diff` | Experiments (unstable) |

## Install

```sh
npx skills add smarchone/skills/<group>/<skill>
```

Each group README lists the exact install commands.
